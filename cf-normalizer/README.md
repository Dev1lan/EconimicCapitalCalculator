# CF Normalizer

Модуль подготовки входных данных для калькулятора денежных потоков. Преобразует банковские сделки из CSV в Parquet для передачи вычислительному ядру на C++.

**Статус:** в разработке. Реализован модуль чтения CSV (`reader.py`).


## Reader

`read_csv(path: str | Path) -> polars.DataFrame` загружает CSV-файл с разделителем `;` и кодировкой UTF-8.

- Чтение выполняется библиотекой **Polars** за один проход.
- Определение типов отключено (`infer_schema=False`): суммы, ставки, даты и коды сохраняются как строки; отсутствующие значения — `null`.
- Состав предметных колонок не ограничивается: входной контракт ещё не утверждён.
- Ошибки открытия и разбора CSV передаются вызывающему коду как исключения.

Пример:

```python
from normalizer.reader import read_csv

deals = read_csv("tests/data/тестовые_сделки_МАИ.csv")
print(deals.shape)  # (55, 48)
```

## Тесты Reader

В `tests/test_reader.py` предусмотрено **11 тестов**:

- Загрузка тестового набора (55 сделок, 48 колонок) и проверка типов Polars.
- Сохранение строковых значений, ведущих нулей и пустых значений (`null`).
- Чтение разделителя `;` внутри кавычек.
- Отсутствие преждевременной финансовой валидации.
- Допуск дополнительных колонок и отсутствующих предметных колонок.
- Обработка отсутствующего и пустого файла, а также строки с лишним полем.
