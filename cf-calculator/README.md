# CashFlow Calculator

Расчетный C++ модуль для генерации контрактных расписаний денежных потоков (Cash Flows) по финансовым инструментам в рамках оценки процентного риска банковского портфеля (IRRBB).


## Реализованная функциональность

* Алгоритмы амортизации основного долга:

* `SIMPLE` — выплата основного долга в конце срока (Bullet) или по явному расписанию траншей (`explicit_principal_steps`) для активов и пассивов (депозитов).

* `ANN` — аннуитетный график с расчетом процентов по фактическому числу дней периода и закрытием остатка долга в ноль на последнем платеже.

* `RGM` — дифференцированный график (равномерное погашение тела долга) с поддержкой синхронных и разнесенных дат выплаты процентов и основного долга.

* Процентные ставки (`FIXED` / `FLOAT`):

* Расчет плавающей ставки на основе базового индикатора (или ключевой ставки ЦБ по умолчанию — `8%`) и маржи с учетом ограничений коридора `Cap` и `Floor`.

* Обработка событий пересмотра ставки (`repricing`): закрытие подпериода начисления по старой ставке с накоплением процентов без создания промежуточной выплаты (`total_cf = 0`) и переключение ставки для следующего периода.

* Календарь и конвенции баз дней:

* Генерация дат с шагом в месяцах (`1M`, `2M`, `3M` и др.), днях (`45D`, `153D`) и в конец срока (`ENDDATE`), поддержка привязки ко дню месяца и концу месяца (`day_num = -1`).

* Расчет долей года по конвенциям `ACT/365` и `ACT/ACT ISDA` (с учетом високосных лет).

## Структура проекта

```text
cf-calculator/
├── CMakeLists.txt
├── include/
│   ├── cf_types.hpp       # Входные (DealInput) и выходные (CashFlowRow) структуры данных

│   └── cf_calculator.cpp
└── tests/
    ├── test_helpers.hpp   # Проверка финансовых инвариантов и сверка строк с эталоном

    ├── test_simple.cpp    # Unit-тесты алгоритма SIMPLE

    ├── test_rgm.cpp       # Unit-тесты алгоритма RGM
    └── test_float.cpp     # Unit-тесты плавающей ставки FLOAT и событий repricing
```

## Требования и сборка

* **Компилятор:** поддержка стандарта **C++20** (используется `<chrono>` для календарных расчетов).
* **Система сборки:** CMake $\ge 3.20$.
* **Зависимости:** основная библиотека `cf_engine` не имеет внешних зависимостей; для сборки тестов автоматически загружается `GoogleTest` (`v1.14.0`).

### Сборка и запуск тестов

```bash
# Конфигурация проекта
cmake -B build -DCF_BUILD_TESTS=ON

# Сборка библиотеки и тестового исполняемого файла
cmake --build build

# Запуск unit-тестов и сверки с эталоном
ctest --test-dir build --output-on-failure
```

Для запуска сборки с проверкой памяти через санитайзеры (GCC/Clang):

```bash
cmake -B build -DCF_BUILD_TESTS=ON -DCF_ENABLE_SANITIZERS=ON
cmake --build build
ctest --test-dir build --output-on-failure
```
